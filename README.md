# Favorite Places

Django-сайт для збереження улюблених місць і випадкового вибору місця, куди можна сходити .

## Запуск проєкту

1. Створити віртуальне середовище:

```bash
python3 -m venv .venv

2. Активувати його :
source .venv/bin/activate

3. Встановити залежності:
pip install -r requirements.txt

4.Запустити сервер:
python manage.py runserver 8008

5.Відкрити в браузері:
http://127.0.0.1:8008/
